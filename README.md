# Deadbolt パスワード金庫

自分専用のパスワード管理アプリです。

- 中身はすべて端末の中で暗号化（AES-256-GCM、鍵はマスターパスワードから PBKDF2-SHA256 60万回で作成）。
- このリポジトリにあるのはアプリの画面と仕組みだけで、パスワードなどのデータは含みません。
- スマホとPCの同期は、Googleドライブの「アプリ専用の見えない場所」に暗号化したまま置いて行います。
